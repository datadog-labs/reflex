# Security

Report suspected vulnerabilities privately to [security@datadoghq.com](mailto:security@datadoghq.com).
Include the affected version or commit, reproduction steps, and potential impact.
Do not include credentials or customer data.

Please do not open a public issue or pull request that discloses a vulnerability.
See [Datadog's reporting guidance](https://www.datadoghq.com/trust/#report-issues)
for contact and encryption information.
