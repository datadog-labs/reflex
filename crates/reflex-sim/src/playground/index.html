INSIDE THIS LITTLE WORLD

Pressure has a memory.

Each service has a fixed worker pool and a bounded queue. Slowdowns affect requests already running. A timeout ends the client's wait, but the downstream keeps doing the work.

More queued and active work builds stress. Stress increases error probability and fades gradually when traffic eases. Repair removes your injected faults without resetting the queue or stress.

Reflex makes the transitions safe.

The current policy opens a circuit when at least 20 responses in a 5-second window contain 50% or more errors or timeouts. After a 3-second cooldown, one recovery probe is admitted. Success closes the circuit; failure reopens it. Reflex checks guards and invariants before committing these transitions.

Choose Threshold for the deterministic policy above, or Jev + Reflex for live model recommendations. Changing policy resets the incident. With local evidence, Jev receives recent client response counts, latency, circuit state, and cooldown eligibility. It does not see fault settings or internal stress. When Toto is enabled, it also receives forecasts of observed arrivals, failures, and queue depth.

With local evidence, Reflex requires at least 10 recent responses before opening, limits recovery to one probe after a 3-second cooldown, and rejects proposals from a prior circuit revision or more than 5 simulated seconds ago. A successful probe closes the circuit automatically. Failed evaluations retain the current state. Choice scores and confidence are shown only when supplied; neither guarantees operational success.

Traffic continues while inference is pending. Results apply on a later simulation tick, never while paused. A faster playback speed can make a response stale. Live inference is capped by the displayed call budget; once exhausted, the current policy stops requesting new judgments. Replay uses recorded responses and makes no API calls.

Animation samples requests for readability. All counters, circuit states, queues, and outcomes come from the Rust simulator.

Datadog evidence mode

When started with Datadog evidence, Jev receives exported client outcomes and server pressure measurements from Datadog. The short window is at least 30 seconds; the long window covers up to two minutes. Window and measurement timestamps are visible in each decision. Missing or stale telemetry retains the current plan and does not call Jev. Breaker control, cooldown, and probe reservation remain in Reflex.

This mode runs at 1× speed for up to ten minutes. Start, reset, resume, and a successful recovery probe require a fresh collection window before opening is allowed. Step and replay are unavailable because Datadog uses wall-clock timestamps. The local evidence mode retains the original controls.

Make an incident worth replaying.

Pause to inspect the system or advance one second at a time. Replay reproduces this session's seed, exact fault edits, and recorded model responses up to the current simulated time. Reset starts fresh with the same seed. Export saves your fault log, request trace, and results. Tabs share one local session.

Sessions last 3 simulated minutes. At the horizon, work can still be in flight; live counters and exports describe the current state, not a fully drained benchmark.
